# Tidal 自动注册系统 - 项目步骤 v0.2.19

> 最后更新：2026-05-08
>
> 用途：按程序真实执行顺序记录步骤 ID、输入来源和坐标/模板来源，后续只要报对应 ID 就能定点修改。
>
> 维护要求：代码流程、坐标、模板、滚轮次数、等待时长、版本号变化时，同步更新本文件、项目记忆文档.md、CHANGELOG.md。
>
> 范围说明：风车邮箱流程仍属于完整主流程的一部分，但不纳入 Tidal 专用坐标脚本；Tidal 站内的固定坐标、模板、滚轮和等待统一由 utils/tidal_coordinates.py 维护。
>
> 当前兜底：若 PyAutoGUI 或模板匹配不可用，modules/tidal_register.py 对多数 Tidal 步骤仍保留 Selenium 元素兜底，避免程序完全不可运行。
>
> 调试记录：从 v0.2.13 起，每个子步骤执行完成后都会立即全屏截图，目录位于 data/logs/screenshots/本次运行时间戳，文件名包含步骤名、日期、时间和毫秒时间戳，并同步写入 manifest.jsonl。
>
> 运行日志：从 v0.2.19 起，每次运行会自动在 data/logs/runtime 生成 run_日期时间.log，保存完整控制台输出。

## 1. 主流程顺序

| 顺序 | ID | 页面/阶段 | 当前动作 | 当前主路径 |
| --- | --- | --- | --- | --- |
| 01 | BOOT-01 | 主程序启动 | 启动 ChromeBrowser、显式匹配本机 Chrome 对应 chromedriver、启用无痕模式、显式允许 JavaScript、只注入最小 webdriver 隐藏脚本、创建 HumanBehavior | 稳定本地驱动链路 + 最小反检测配置 |
| 02 | TD-PRE-01 | Tidal 首页预检查 | Chrome 启动后固定等待 5 秒，先 driver.get 打开 https://link.tidal.com/RGZST，并固定等待 20 秒 | link.tidal 预检查 + 固定等待 |
| 03 | TD-00-ACCESS-RESTRICTED | Tidal 首页预检查 | 对 access_restricted.png 做多尺度模板匹配；若高阈值命中、页面文案命中，或低阈值命中分数达到 0.45，则按访问受限处理并提示用户输入 y 继续复查 | 模板匹配 + 页面文案检测 + 人工确认 |
| 04 | TD-01-TRANSLATION | Tidal 首页 | 匹配 chrome_translation.png，命中后点 1419,103 关闭翻译弹窗 | 模板 + 固定点击坐标 |
| 05 | TD-01-COOKIES | Tidal 首页 | 匹配 tidal_cookies.png，命中后点 713,803 接受 Cookie | 模板 + 固定点击坐标 |
| 06 | TD-PRE-02 | Tidal 首页预检查后 | 访问受限检测通过后，新开一个 tidal.com 标签页作为主注册页，再处理翻译/Cookie 弹窗 | 新标签直开 + 模板弹窗处理 |
| 07 | EM-01 | 风车邮箱 | 新开邮箱标签页并打开 mail.xoxome.online | DOM 流程，不进入 Tidal 坐标脚本 |
| 08 | EM-02 | 风车邮箱 | 检查是否已登录；若页面已有“生成邮箱/同步邮箱”则跳过登录 | DOM 文本检测 |
| 09 | EM-03 | 风车邮箱登录页 | 填写用户名输入框 | DOM 直填 |
| 10 | EM-04 | 风车邮箱登录页 | 填写密码输入框 | DOM 直填 |
| 11 | EM-05 | 风车邮箱登录页 | 点击“登录”按钮 | DOM 点击 |
| 12 | EM-06 | 风车邮箱生成页 | 选择邮箱后缀 | DOM 下拉选择 |
| 13 | EM-07 | 风车邮箱生成页 | 点击“生成邮箱”按钮 | DOM 点击 |
| 14 | EM-08 | 风车邮箱生成页 | 固定等待 10 秒，让系统生成邮箱 | 固定等待 |
| 15 | EM-09 | 风车邮箱生成结果 | 点击“复制”按钮 | DOM 点击 |
| 16 | EM-10 | 风车邮箱生成结果 | 优先从剪贴板读取邮箱，失败则从生成结果输入框或页面文本提取邮箱地址 | 剪贴板 + DOM 提取 |

## 5. 维护规则

1. 每次代码修改后，先递增版本号。
2. 每次代码修改后，同步更新 main.py、CHANGELOG.md、项目记忆文档.md、项目步骤.md。
3. 版本更新说明和 Git 提交标题都使用“v版本号：中文说明”。
4. 风车邮箱流程如果后续要坐标化，单独立项，不混进 utils/tidal_coordinates.py。
5. 若要排查流程问题，优先查看 data/logs/screenshots 下最新一次运行目录里的截图顺序和 manifest.jsonl。
